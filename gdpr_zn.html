隐私政策 (GDPR)

最后更新：2026年4月 (v1.1)

1. 数据处理原则

StakeForge 系统遵循最小数据收集原则。我们仅存储平台运行和用户身份识别所必需的数据。

2. 收集的数据范围

在注册和使用过程中，我们会收集以下数据：

  • 身份标识： 用户名和电子邮件地址。
  • 安全信息： 加密密码（以哈希形式存储——我们无法获取原始密码）。
  • 账户余额： 当前 DEMO 和 REAL 账户余额。
  • 财务数据： 与账户关联的唯一 BTC 钱包地址（如适用）。
  • 技术数据： 地理位置（仅用于访问权限验证和地理封锁，不存储 IP 地址）。

3. 限制（地理封锁）

服务提供商根据适用法律实施地理限制。 来自匈牙利 IP 地址的用户无法使用 REAL（真实资金）充值功能或生成 BTC 钱包地址。 此类用户只能使用 DEMO 功能。

4. 数据安全与第三方

您的数据存储在加密的 Supabase 云平台上。 个人数据（电子邮件、用户名）不会被共享或出售给第三方。 数据仅用于身份验证、账户管理和平台运行。

5. 您的权利

您可以随时请求导出、修改或永久删除您的数据。 删除后，所有个人数据（电子邮件、钱包地址）将从系统中移除。 交易记录可能会以匿名形式保留用于统计目的。
