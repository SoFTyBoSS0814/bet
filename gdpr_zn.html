隐私政策

最后更新时间：2026年6月 (v1.2)

本文件构成了 StakeForge 平台的官方隐私政策。数据控制者特此根据适用法律，就个人数据处理的流程、条件和保障措施向平台用户（以下简称“数据主体”或“用户”）进行说明。

I. 数据控制者的身份与联系方式

就用户的个人数据而言，数据控制者的职责由本平台的国际运营商履行。

数据控制者名称： StakeForge International (Austria)

官方数据保护联系邮箱： support@stake-forge.com

II. 数据处理原则

数据控制者声明，个人数据的处理将严格遵守合法、公正、透明、目的限制、数据最小化、准确性、存储限制、完整性和保密性的原则。

III. 处理数据的范围、目的、法律依据和期限

基于数据最小化原则，数据控制者将数据处理业务分类执行如下：

1. 注册与身份验证数据

处理的数据： 系统生成的唯一识别码 (UUID)、用户名、电子邮箱地址。
处理目的： 对数据主体进行身份验证、创建用户账户（注册）、提供构成合同标的的业务服务以及进行官方沟通。
法律依据： 履行合同。
数据留存期限： 用户关系存续期间（直至注销注册）。

2. 安全与认证数据

处理的数据： 单向加密（哈希）的密码。数据控制者明确声明，其不知道也不在其 IT 系统中存储原始明文密码。
处理目的： 确保用户账户的完整性并防止未经授权的访问。
法律依据： 履行数据控制者所承担的法律义务（法律规定的数据安全保障）。
数据留存期限： 用户关系存续期间。

3. 财务与资产相关数据

处理的数据： 分配给用户的 DEMO（虚拟）余额当前状态、REAL（真实）余额状态、唯一的 BTC（比特币）钱包地址。
处理目的： 平台内部经济活动（投注、派奖）以及充值和提现交易的技术与会计执行。
法律依据： 履行合同。
数据留存期限： 直至注销用户账户，但须服从适用财税法律所规定的强制性法定诉讼时效和留存期限。

4. 交易与投注日志数据

处理的数据： 交易/投注的唯一识别码 (UUID)、市场识别码、用户的唯一识别码 (User UUID)、结果说明、采用的赔率倍数 (odds)、投注金额、交易类型、交易的法律状态。
处理目的： 服务技术运行的结算、系统完整性的法律保护，以及欺诈行为的预防和发现。
法律依据： 履行合同，以及数据控制者在维护安全方面的合法利益。
数据留存期限： 在注销账户的情况下，个人关联（User UUID）将被立即且不可逆地切断。关系终止后，系统仅以聚合、匿名化的形式存储这些数据，因此这些数据属于统计数据，不属于隐私法律的管辖范围。

5. 网络与技术数据

处理的数据： 用户终端设备网络 IP 地址。
处理目的： 实时执行基于地域的访问控制（Geo-blocking/地理拦截）并确保符合适用的监管要求。
法律依据： 履行法律义务（遵守国际博彩法规和反洗钱法）。
数据留存期限： 数据库中不进行记录。对 IP 地址的处理严格限于在内存中对网络流量进行瞬时分析。

IV. 关于地域限制（地理拦截）的法律声明

为了遵守国际和国内的监管要求，数据控制者实施了严格的基于网络的过滤。对于从匈牙利 IP 地址连接的用户，本网站仅提供对 DEMO（虚拟、不具备金钱价值）功能的访问。 对于此类用户，激活 REAL（真实）财务余额和生成 BTC 钱包地址在技术上是被屏蔽的。

数据控制者明确声明，任何旨在绕过上述技术限制的行为（包括但不限于使用虚拟专用网络 - VPN - 或代理服务器）均构成对服务条款的实质性、单方面违约，这将导致立即终止用户账户，且不承担任何损害赔偿责任。

V. 国际数据传输与数据处理者

为了提供平台所需的 IT 基础设施，数据控制者使用 Supabase Inc.（总部位于：1355 Market St, Suite 488, San Francisco, CA 94103, USA）的云端数据库服务作为其数据处理者。鉴于该数据处理者位于欧洲经济区 (EEA) 之外，数据传输的合法性由欧洲委员会批准的标准合同条款 (Standard Contractual Clauses - SCC) 提供保障，从而满足了高水平的数据保护要求。

数据控制者声明，无论是免费还是收取对价，其均不会为了营销或市场研究的目的向第三方转让个人数据。

VI. 数据安全与技术防护

数据控制者承诺采取符合科学技术发展现状的技术和组织措施来确保数据安全。网络通信毫无例外地均通过加密（TLS/SSL）通道进行。数据库访问控制通过行级安全（Row Level Security - RLS）策略强制执行，该架构形成了防止未经授权访问数据的技术壁垒。

VII. 数据主体的权利及其行使

数据主体可通过向 support@stake-forge.com 电子邮箱地址发送声明来行使以下权利：

  • 知情权与访问权： 数据主体有权确认其个人数据是否正在受到处理，并有权索取被处理数据的副本。
  • 更正权： 数据主体有权要求更正不准确的数据或补充不完整的数据。
  • 删除权（“被遗忘权”）： 数据主体有权申请永久删除其账户及所有个人数据。
  • 限制处理权： 在发生法律纠纷或怀疑存在非法处理的情况下，数据主体有权要求暂停数据处理业务。
  • 数据可携权： 数据主体有权以结构化、机器可读的格式（例如 JSON 格式）获取其提供的数据，或将这些数据传输给另一个控制者。
  • 反对权： 基于自身特定情况的理由，数据主体有权对基于合法利益进行的个人数据处理提出反对。

关于反对权的具体警告： 本平台的技术、财务和会计系统构成了一个不可分割的整体。如果数据主体行使其反对权并禁止处理交易和安全日志数据，这将在技术上和法律上导致无法提供服务。因此，数据控制者告知数据主体，行使反对权在法律效力上将导致立即且永久地注销（删除）用户的注册账户。

数据控制者应当在收到申请后毫无不当延误地进行评估和履行，最晚不得超过一个月（30天），此项服务是免费的。

VIII. 申诉与司法救济条款

如果数据主体认为数据控制者的活动违反了关于个人数据保护的法律规定，可以采用以下法律救济途径：

  • 与数据控制者协商： 建议首先向数据控制者（support@stake-forge.com）反映涉嫌侵权的情况，以便和平、快速地解决问题。
  • 向监管机构投诉的权利： 数据主体有权向主管监管机构提出投诉。在匈牙利境内，主管机构为国家数据保护与信息自由局（NAIH；地址：1055 Budapest, Falk Miksa utca 9-11.，网址：www.naih.hu）。
  • 获得有效司法救济的权利： 无论行政救济结果如何，数据主体均有权向数据控制者所在地或数据主体自身国内常住地（居住地）管辖法院提起诉讼。
